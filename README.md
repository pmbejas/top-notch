# Top-Notch — Global Career & Interview Performance

Sitio web interactivo para **Top-Notch** (*Global Career & Interview Performance Program — 12 Semanas*), dirigido por **Luciano Ezequiel Caferro**.

## Características

- **Next.js 15 (App Router) + TypeScript Estricto**
- **Tailwind CSS v4 + Animaciones Fluidas (`motion/react`)**
- **Internacionalización (`next-intl`)**: Soporte en Español (`es`), Inglés (`en`) y Portugués (`pt`).
- **Menú Flotante Inferior (Bottom Dock)** con detección automática de sección activa y formulario conectado a WhatsApp.

## Requisitos

- Node.js 20+
- npm 10+

## Ejecución Local

1. Copiar variables de entorno de ejemplo:
   ```bash
   cp .env.example .env.local
   ```
2. Instalar dependencias:
   ```bash
   npm install
   ```
3. Iniciar servidor de desarrollo:
   ```bash
   npm run dev
   ```
